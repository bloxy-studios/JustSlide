# ADR 0004 — ADS usage under a licence gate
Status: Accepted for development; **release blocked on owner/legal decision**. Use Apache-2.0 `@atlaskit/*` code packages for tokens/primitives/menus; do not copy ADS visual assets or ship Atlassian Sans/Mono; keep Figma's own assets. Rationale: ADS Licence (13 Mar 2025) scopes use to Atlassian Add-Ons while §8 lets OSS components be used under their own licences. If legal rejects even the Apache-2.0 packages, the Slide token layer and components are structured so `token()` calls can be replaced by an original token set without layout changes.
